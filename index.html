Guía de Conexión en OpenCode

1 Comando /connect

En la terminal de OpenCode (TUI), escribe /connect, selecciona OpenCode Go y pega tu API key obtenida en OpenCode Console.

2 ID del Modelo

Usa el formato con prefijo opencode-go/<model-id>.
Ejemplo: opencode-go/deepseek-v4.1-flash

3 Endpoint & SDK

Endpoint oficial:
https://opencode.ai/zen/go/v1/chat/completions
Compatible con paquete: @ai-sdk/openai-compatible
